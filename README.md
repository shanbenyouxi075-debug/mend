mend is one command-line tool that applies the edits AI models write, in all four formats they use: unified diffs (with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and text-editor tool calls as JSON. It finds the lines each edit names at the first of three matching tiers, so drifted whitespace and indentation still land, and it writes every change or none.

## Run it

```sh
node main.ts [options] [PATCH]
```
